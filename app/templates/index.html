      選ぶ。印を付ける。コピーする。
      
          
      左の一覧でサービスとコマンドを選びます。入力したオプションには蛍光ペンの印が付き、画面上部のコマンドが入力に合わせて組み上がります。すべてのコマンドに公式リファレンスへのリンクが付いています。
      
        
      
        
      
      
      

      
      
        
      How to use
      
        
        
          
      1. Find a commandPick a service and then a command on the left, or search above. Search matches the start of words in command names (e.g. inst → describe-instances), ec2 stop narrows to EC2, and Japanese such as「インスタンス 一覧」also works.
        2. 
          
      2. Or paste a commandPaste an aws … command from a blog or the docs into the search box (or anywhere on the page) to open it with the fields filled in. Nothing is executed.
        3. 
          
      3. Fill in parametersThe command at the top is assembled as you type; click an option in it to jump to its field. Commands that delete or stop resources are marked in red or yellow, with an “Add --dry-run” button when available.
        4. 
          
      4. CopyChoose Bash / PowerShell / Command Prompt / .bat file / one line, then press “Copy command”. Line continuations and quoting follow the format.
        5. 
          
      5. Save to favoritesSave with a name and a memo via “＋ Add to favorites”. Open them with “★ Favorites” and restore one with “Open in builder”. Export/import as JSON.
        6. 
        
      
      
      
      
      
        
      使い方
      
        
        
          
      1. コマンドを探す左の一覧でサービス → コマンドの順に選ぶか、上の検索欄で探します。検索はコマンド名の単語の先頭で一致し（例: inst → describe-instances）、ec2 stop のように書くと EC2 に絞れます。「インスタンス 一覧」のような日本語でも探せます。
        2. 
          
      2. コマンドを貼り付けるブログやドキュメントの aws … を検索欄（または画面のどこか）に貼り付けると、入力欄が埋まった状態で開きます。貼ったコマンドは実行されません。
        3. 
          
      3. パラメータを入力する画面上部のコマンドが入力に合わせて組み上がります。コマンド内のオプションを押すと、その入力欄へ移動します。削除・停止などの操作は赤・黄色で示し、使えるときは「Add --dry-run」ボタンも出ます。
        4. 
          
      4. コピーするBash ／ PowerShell ／ コマンドプロンプト ／ .bat ファイル ／ 1行 から形式を選んで「Copy command」。改行記号と引用符が形式に合わせて変わります。
        5. 
          
      5. お気に入りに残す「＋ Add to favorites」で名前とメモを付けて保存。「★ Favorites」から開き、「Open in builder」で入力内容ごと呼び出せます。JSON でエクスポート／インポートもできます。
        6.
